---

**DMR Cepte** is an amateur radio app for phones and Android POC radios that connects to
BrandMeister, ADN Systems, FreeDMR, TGIF, EchoLink and NXDN.

- **Idea and direction:** Hasan Ali YÜCEL (TA6HY)
- **Code:** all of it — network links, AMBE+2 audio, recording, contacts, APRS, web panel and
  interface — was written by **Claude**, Anthropic's AI.

This repository hosts the latest APK, `surum.json` and the release history for in-app updates.
